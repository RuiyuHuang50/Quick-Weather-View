# Privacy Policy for Quick Weather View Extension

**Last Updated:** May 1, 2025 Thank you for using the Quick Weather View Chrome Extension ("the Extension"). This policy explains what information the Extension handles and how it is used.

**1. Information Handled by the Extension**

The Extension requires certain information provided by you to function correctly:

- **OpenWeatherMap API Key:** You must provide your own free API key from OpenWeatherMap. This key is stored **only locally** on your computer using Chrome's `chrome.storage.local` API and is **never transmitted to the developer** of this Extension.
- **Saved Cities List:** The list of city names you add manually (via popup input or context menu) is stored **only locally** on your computer using Chrome's `chrome.storage.local` API.
- **Home City:** The city name you designate as your 'Home City' in the options is stored **only locally** on your computer using Chrome's `chrome.storage.local` API.
- **Temperature Unit Preference:** Your choice of Celsius or Fahrenheit is stored **only locally** on your computer using Chrome's `chrome.storage.local` API.

**2. How Information is Used**

- **API Key and City Names:** Your stored API key and the city names (Home City or selected/saved cities) are sent directly to the OpenWeatherMap API ([https://openweathermap.org/](https://openweathermap.org/)) solely for the purpose of retrieving current weather data and forecasts requested by you through the Extension's features (popup display, badge update, context menu check). We recommend reviewing OpenWeatherMap's own privacy policy regarding how they handle this data.
- **Local Storage:** All data mentioned above is stored locally within your Chrome browser profile to allow the Extension to remember your settings and cities between browser sessions. This data remains on your computer unless you uninstall the Extension or clear the storage manually.

**3. Data Collection by the Developer**

The developer of Quick Weather View **does not collect, remotely store, track, share, or sell any personal information or user data**, including your API key, city lists, or Browse activity. The Extension functions entirely within your browser.

**4. Browse History and User Activity**

The Extension **does not** access, track, or store your web Browse history or any other user activity (like clicks or keystrokes).

**5. Changes to This Privacy Policy**

This policy may be updated occasionally. Any changes will be reflected in the updated policy available within the Extension's description or accompanying documentation.

**6. Contact Us**

If you have any questions about this Privacy Policy, please contact the developer via thinknovatech@gmail.com.
