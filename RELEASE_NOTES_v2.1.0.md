# Release Notes - Version 2.1.0

## 🎉 Major Update: Simplified Setup Experience

### What's New:

**✨ No API Key Setup Required**
- Users no longer need to obtain their own OpenWeatherMap API key
- Weather data access is now included and managed by the extension developer
- Instant functionality after installation - just add cities and start checking weather!

**🎯 Streamlined User Experience**
- Removed complex API key configuration from options page
- Simplified options page focuses on core settings (Home City and Temperature Units)
- Immediate access to all weather features upon installation

**🔧 Technical Improvements**
- Updated to use developer-managed API access
- Improved error handling and user feedback
- Enhanced stability and reliability

### For Existing Users:

If you're upgrading from a previous version:
- Your saved cities and preferences will be preserved
- You can remove any stored API key from the old version (it's no longer needed)
- All features will work immediately without any additional setup

### What Stays the Same:

- All your favorite features: multi-city weather cards, context menu weather checks, badge temperature display
- Temperature unit switching (Celsius/Fahrenheit)
- Home city configuration for badge display
- Privacy-focused: your data stays on your device

---

Thank you for using Quick Weather View! Enjoy the simplified experience.
